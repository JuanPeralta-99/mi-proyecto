# Proyecto Fullstack - Sistema de Tareas

Este proyecto es un ejemplo de **aplicación fullstack** que incluye un **frontend en React (Vite)**, un **backend en Node.js (Express)** y pruebas automatizadas con **Vitest**, **Playwright** y **Locust** para asegurar la calidad y rendimiento del sistema.

---

## Tecnologías utilizadas

- **Frontend:** React + Vite
- **Backend:** Node.js + Express
- **Base de datos:** SQLite (opcional)
- **Pruebas unitarias y de integración:** Vitest, jsdom, Jest, Supertest
- **Pruebas E2E:** Playwright
- **Pruebas de carga:** Locust
- **CI/CD:** GitHub Actions
